## twente-match-thread-

This is a simple Reddit bot that automatically posts match discussion threads for r/FCTwente.

### What it does
- Fetches upcoming match data from football-data.org
- Posts a discussion thread before kickoff
- Stickies and flairs the thread

### Data usage
- The app stores match fixture data (teams, kickoff times, competition names) in Reddit's built-in storage (Redis)
- No personal user data is collected, stored, or shared
- The app only interacts with the subreddit where it is installed
